# Contribuir

1. Crea una rama desde `main`.
2. Cambia `src/` (nunca `dist/` a mano) y ejecuta `npm run build`.
3. Pasa `./run_tests.sh`: motor, e2e y axe con 0 infracciones.
4. Abre una PR con qué cambia, por qué y capturas si toca la interfaz.

El contenido debe ser de redacción propia. Las capturas, sintéticas y con direcciones y dominios de laboratorio.
